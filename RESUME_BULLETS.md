# Resume Bullets

- Built **PayPulse**, an end-to-end UPI reliability analytics project using official NPCI bank/PSP statistics, transforming published approval/decline metrics into reproducible SQL and Power BI-ready models.
- Applied **CTEs, window functions, ranking, Pareto contribution and weighted-rate analysis** to compare Technical Decline % with estimated absolute failed transaction volume and prioritize high-impact reliability issues.
- Added automated **data-quality checks**, an Excel management report and documented analytical limitations to distinguish observed NPCI metrics from derived estimates and avoid unsupported business-impact claims.
